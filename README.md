# KuroManga Store

Aplicación web e-commerce desarrollada con TypeScript para la gestión y visualización de un catálogo de mangas.

## Tecnologías
- TypeScript
- HTML
- CSS

## Funcionalidades
- Catálogo de productos
- Visualización de mangas
- Navegación de contenido
- Interfaz orientada al usuario

## Estado
Proyecto académico y personal desarrollado con fines de aprendizaje.
